## Project Overview
This is a fully styled 5‑page website for **The Artisan Bakery**, a local small business. It uses HTML5 and CSS3 to create a warm, professional look. The site includes a responsive navigation bar, product gallery, enquiry form, and contact details.

## Website Goals and Objectives
- Increase online visibility and attract new customers.
- Simplify custom order placement via a enquiry form.
- Build brand loyalty with a clean, engaging design.

## Key Features and Functionality
- **Home:** Hero section, daily specials, quick links.
- **About:** Bakery history and values.
- **Products:** Categorized gallery with images and prices.
- **Enquiry:** A functional HTML form for custom orders.
- **Contact:** Address, phone, email, and Google Maps embed.
- **Responsive design** using CSS media queries.
- **Consistent navigation** across all pages.
