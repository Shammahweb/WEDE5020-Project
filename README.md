## Project Overview
This is a 7-page website for The Artisan Bakery, a local small business that sells artisan bread, pastries and custom cakes. The website was built using HTML5, CSS3 and JavaScript. It includes a working shopping cart so customers can buy products online without having to send an enquiry first.

## Website Goals and Objectives
- Increase online visibility and attract new customers.
- Let customers buy products directly using a shopping cart.
- Make custom orders simple with an online enquiry form.
- Build a friendly and professional brand image.
- Make sure the website works on phones, tablets and computers.

## Pages on the Website
| Page | File | Purpose |
|------|------|---------|
| Home | index.html | Welcome message, Today's Specials, quick links |
| About | about.html | Bakery story, values and interior photo |
| Products | products.html | Breads, pastries and cakes with Add to Cart buttons |
| Cart | cart.html | Shows items added to cart, allows quantity changes |
| Checkout | checkout.html | Customer details form and order summary |
| Enquiry | enquiry.html | Custom order form for cakes and catering |
| Contact | contact.html | Address, phone, email, map and general message form |

## Key Features
- **Responsive Design** – Works on all screen sizes using media queries.
- **Mobile Menu** – Hamburger menu for phones.
- **Product Tabs** – Switch between Breads, Pastries and Cakes.
- **Image Lightbox** – Click a product image to see it larger.
- **Product Search** – Type to filter products.
- **Shopping Cart** – Add to cart, change quantities, remove items.
- **Form Validation** – JavaScript checks the forms before submitting.
- **localStorage** – Cart items are saved even if you close the browser.
- **SEO Files** – robots.txt and sitemap.xml for search engines.

## How to Run the Website Locally
1. Clone the repository from GitHub.
2. Open the folder in Visual Studio Code.
3. Right-click on index.html and choose "Open with Live Server".
4. The website will open in your browser.

## How the Shopping Cart Works
1. Go to the Products page.
2. Click "Add to Cart" on any product.
3. The cart counter in the header will update.
4. Click the cart icon to view your cart.
5. Change quantities or remove items if needed.
6. Click Checkout to enter your details.

## How the Forms Work
- The Enquiry form is for custom orders (cakes and catering).
- The Contact form is for general messages.
- Both forms use JavaScript validation before submitting.
