## Project Overview
A fully styled 5-page website for **The Artisan Bakery**, a local small business. Built with HTML5 and CSS3, the site delivers a warm, professional look with a responsive navigation bar, product gallery, custom order enquiry form, and full contact details including a Google Maps embed.

## Website Goals and Objectives
- Increase online visibility and attract new customers.
- Simplify custom order placement via an enquiry form.
- Build brand loyalty with a clean, engaging design.
- Provide a mobile-friendly experience for local customers.

## Key Features and Functionality
- **Home** – Hero section, Today's Specials, quick links.
- **About** – Bakery history, mission, and interior photo.
- **Products** – Three categories (Breads, Pastries, Cakes) with 9 items, images, and prices.
- **Enquiry** – Functional HTML form with name, email, phone, order type, and message fields.
- **Contact** – Address, phone, email, opening hours, and embedded Google Map.
- **Responsive design** using CSS media queries.
- **Consistent navigation** across all pages.
- **Custom colour palette** (warm brown, cream, golden yellow) and Google Fonts (Playfair Display + Open Sans).

## Technology Stack
- **HTML5** – Semantic structure
- **CSS3** – Flexbox, media queries, custom styling
- **Google Fonts** – Playfair Display, Open Sans
- **Google Maps Embed** – Contact page location
- **Git & GitHub** – Version control and hosting
